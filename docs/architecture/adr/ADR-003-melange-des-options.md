# ADR-003 — Mélange des options à l'affichage, correction en ordre d'origine

- **Statut :** acceptée (v1)
- **Contexte :** dans la première version des sources TOGAF, la meilleure réponse était en position A pour 391 questions sur 648 (60 %). Le dépôt de cours a été rééquilibré le 1er novembre 2026 (≈ 25 % par lettre), mais un ordre fixe reste mémorisable quand on refait les mêmes questions. Les explications citent les options par leur lettre (« A relève de la Phase D… »), ce qui empêche de réordonner les sources.
- **Décision :**
  1. Les options sont mélangées à la création de chaque session ; pendant la question, elles sont affichées **sans lettre**.
  2. Dans la correction, les options sont rappelées **dans l'ordre d'origine avec leur lettre**, pour que l'explication reste juste.
  3. Les sources ne sont pas modifiées ; la répartition des positions est rapportée par le validateur à titre d'information.
  4. Pour un barème gradué (5/3/1/0), la correction présente les options de la meilleure à la moins bonne, chacune avec sa justification.
- **Conséquences :**
  - ✓ Aucune position n'est privilégiée (≈ 25 % chacune, vérifié par un test).
  - ✓ Les explications existantes restent valables sans réécriture.
  - ✗ L'utilisateur voit deux ordres différents (question puis correction) ; atténué par le libellé « L'explication désigne les options par leur lettre d'origine ».
